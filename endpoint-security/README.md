# Endpoint Security Scripts

PowerShell-driven config for:
- Microsoft Defender (policies, exclusions, scan schedules)
- Windows Firewall (profile rules, logging)
- Attack Surface Reduction (ASR) rules
- BitLocker recovery key escrow verification
- LAPS (local admin password solution) state

> ⚠️ Scripts that touch BitLocker, Secure Boot, or TPM require a second reviewer before deploy.
